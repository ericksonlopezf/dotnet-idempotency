## 3. Before Opening an Issue

To help us resolve your issue efficiently:

1. **Verify against the Showcase**: Run `dotnet run --project samples/Showcase/EricksonLopez.Idempotency.Showcase.csproj` to see standard reference implementations.
2. **Search Existing Issues**: Check if a similar problem has already been reported or resolved.
3. **Include a Minimal Reproducible Example**: Provide a concise code snippet, target database engine, and log traces.
